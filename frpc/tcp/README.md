# TCP 通道（当前在用的对外通道）

| 项 | 值 |
| --- | --- |
| 类型 | `tcp` + **面板里开的「自动 HTTPS」**（不开就被国内节点拦，见下） |
| 本地 | `127.0.0.1:7891`（必须等于 `tools/service.mjs` 的 `PORT`） |
| 公网 | **https://<你的公网地址>** —— `<节点域名>` 会按访客线路解析到 移动/电信/联通 三个节点 |
| 节点 | 国内节点（`yd.` / `dx.` / `lt.<节点域名>`） |

**访客必须用 `https://`**：`http://<你的公网地址>` 会被节点的合规策略拦掉，
回一张 SakuraFrp 自己的 501 页、字节根本不到本机（实测钉死过，见 `../../docs/TUNNEL.md` 坑五）。
开了「自动 HTTPS」之后 **TLS 在 frpc 里终止、脱壳后仍用明文 HTTP 连本机 7891** ——
所以服务端代码一行都不用改，这条也**不违反**"服务端只讲明文 HTTP"的硬约束。
⚠️ 证书是 frpc 现场生成的**自签**证书，访客第一次打开要点一次「继续前往」。

**为什么选它**：Cloudflare 免费版会把中国大陆访客甩到洛杉矶边缘节点
（实测首字节 1.34 秒、间歇 503/522、另有约 12% 新建连接卡满 60 秒）；
国内 TCP 绕开 Cloudflare 和海外节点，实测 **TCP 连接 35~74ms**、
**30 次 WebSocket 握手 0 次卡住**。理由、代价与被否掉的选项见 `../../docs/DECISIONS.md` D15。

**怎么判断"通了没有"**：一条命令 ——
`node tools/check-tunnel.mjs https://<你的公网地址> --ws 30`（三步合一 + 30 次握手）。
手敲版只认 `data/server.log` 里的 `[来访] ... host=<你的公网地址>` ——
面板/启动器显示"在线"不算证据。详见 `../../docs/TUNNEL.md` 第二节。

## 这个文件夹里的文件

- `frpc.ini.example` —— 脱敏模板，**手动模式**（自己跑 frpc）时照它填。
- `frpc.local.ini` —— ⚠️ **2026-10-20 手动模式留下的旧配置，已作废**：
  节点写的是 `<节点域名>`、远端端口 `<端口>`、本地写 `localhost`，那条隧道（`<隧道 ID>`）早就删了。
  留在这里只是存档，**别照着它改**。它带真实密钥，已在 `.gitignore` 里，不要提交、不要外发。
