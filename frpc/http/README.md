# HTTP 通道（已停用，保留）

2026-10-20 ~ 2026-10-21 用过的对外通道：

```
访客 ──HTTPS──► Cloudflare（CNAME + 小黄云 + SSL 模式「灵活」）
      ──HTTP───► SakuraFrp HTTP 隧道（日本2 节点 <节点域名>）
      ──HTTP───► 本机 127.0.0.1:7891
```

公网地址是 `https://<你的域名>/`。**2026-10-21 起停用**，改用 `../tcp/` 那条国内 TCP 通道
（原因与代价见 `../../docs/DECISIONS.md`）。

**为什么留着而不是删掉**：以后有了公网 IP、或者想给访客 HTTPS 时，这套配置可以照原样再开一遍，
不用重踩一遍坑。重新启用前必读 `../../docs/TUNNEL.md` 的坑二、坑三。

⚠️ 停用之后 `<你的域名>` 现在会直接返回 **503**（SakuraFrp 节点侧的错误页），
不是"网站坏了"，是这条通道没人管了。
