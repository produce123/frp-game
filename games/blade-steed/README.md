# 刀马 BladeSteed

武侠猜拳对战：**赢的人才能动手**。买刀、买马、出城、进城、砍一刀 —— 2 到 4 个人，
一台手机就能玩。

- **人机对局**：一个人也能玩，剩下 2–4 个席位由 AI 补齐（AI 和你看到的信息完全一样）。
- **在线对局**：建一个房间，把 6 位房间号念给朋友，或者直接一键邀请在线好友。
  人机是**房间里的座位**：房主按一下「＋ 添加人机」就多一个座位（最多 4 个座位，按「移除」撤掉）。
  **一个人时至少要 2 个座位才开得起来**（只有一个座位的对局永远分不出胜负）——
  座位不够时「开始游戏」是灰的，旁边会写清按哪里补；补够座位就能开局。
  有真人朋友进来时，人机会**让位**（开局前它自动退到后面去）。
  **人机的名字是单字池里的一个字**（虎 / 狼 / 鹰…，挑房里没人用过的），
  **地图上是灰虚线圈**，一眼就能看出哪个座位不是人；
  它和你看到的信息一样多（谁出了拳、谁多少血、谁在哪），但它**未揭晓的拳一样看不到**。

游戏入口是**平台首页的游戏卡片**（点进去就是 `/games/blade-steed/`）。
名字和 ID 来自你的平台账号，游戏里不会再问你叫什么。

---

## 一句话规则

每回合先**同时猜拳**，赢的人用行动步数做事情（买东西、走路、打人），
把别人打到 0 血，最后活着的人赢。

---

## 人数与胜负

- 支持 **2 / 3 / 4 人**，开局随机分配座位号。
- 每人固定 **10 点血**，血量 ≤ 0 立刻出局。
- 场上只剩一个人时，他获胜。
- 一局结束后，**房主**可以点「再来一局」，所有人回到准备界面再来一把（换新的一局，血量装备全部重置）。

## 位置：只有两种

| 位置 | 说明 |
| --- | --- |
| **某人的城里** | 开局时每个人都在**自己的城**里 |
| **野外** | 全局唯一的一片公共区域 |

- **城是永久的**：城主出局了，他的城依然存在，别人照样能进。
- 进城时可以选**任何一座城**：自己的、别人的、出局者的，都行。

## 装备：买一次，永久有效

| 装备 | 效果 | 条件 |
| --- | --- | --- |
| 🔪 **刀** | 【刀】：扣对方 **1 点血** | 自己在城里 · 只能买一次 |
| 🐴 **马** | 【踹】：扣对方 **3 点血**，并把他**踢到野外** | 自己在城里 · 只能买一次 |

**买东西不花钱，但要花一步行动。**

## 每回合流程

1. **全员同时猜拳**（石头 / 布 / 剪刀）。别人的拳在揭晓前谁都看不到，包括服务器下发的报文里也不会有。
2. **恰好 1 人获胜** → 他获得 **2 步行动**。
3. **多人获胜** → 每人 **1 步**；获胜者之间再猜一次拳，淘汰到唯一一人，
   由**他来指定**这几位获胜者的行动顺序。
4. **没有人获胜**（三种手势齐全，或者大家出的一样）→ 重新猜拳。
5. 行动者按顺序把步数花掉。**1 步 = 1 个操作**，2 步可以任意组合，
   也可以随时「结束行动」放弃剩下的步数。
6. 所有人行动完，进入下一回合。

## 可以做哪些事

| 操作 | 条件 |
| --- | --- |
| 🔪 买刀 | 自己在城里，且还没买过 |
| 🐴 买马 | 自己在城里，且还没买过 |
| 🚶 出城 | 自己在城里 |
| 🏯 进城 | 人在野外，选一座城（谁的都行） |
| 🔪 刀某人 | 已有刀，且**双方在同一个位置**（同城，或同在野外） |
| 🦶 踹某人 | 已有马，且**双方在同一座城里**（踹完对方去野外） |
| ✋ 结束行动 | 随时 |

界面上的按钮**只会出现当前真正能做的操作** —— 这些按钮和服务器校验用的是同一份判断，
所以不会出现「点得动但被服务器拒绝」。

## 时限与掉线

| 阶段 | 时限 | 超时怎么办 |
| --- | --- | --- |
| 猜拳 | 10 秒 | 系统随机替你出 |
| 定行动顺序 | 15 秒 | 按座位号自动排序 |
| 每 1 步行动 | 60 秒 | 自动结束你剩下的步数 |

- **掉线保留座位 2 分钟**，回来还是原来的座位，对局继续。
- **主动离开房间 = 判出局**（剩下的人继续打）。
- 中途加入：房主可以在准备界面选**允许 / 不允许**。允许的话，新来的人从**下一个猜拳回合**开始参与。

## 界面上的几个小东西

- 右上角的圆圈是**倒计时**，剩 3 秒时会变红并响一下。
- 顶栏「☰」（人机对局里）是**对局菜单**：重新开局 / 音效 / 特效 / 退出。
- 首页底部的**音效 / 特效**开关会记在本机，下次进来还是你上次的选择。
  系统开了"减少动态效果"的话，特效默认是关的。
- 屏幕中间飘的字是**播报**：谁赢了、谁买刀了、谁被砍了。牌桌下方还有一份文字记录。
- **点下去本机不先演**：出拳 / 行动按下去之后，画面**不会**立刻替你演一遍，
  而是等服务端把这一步推回来再演（联机时这段延迟是**刻意**的 ——
  先演一遍的旧做法在快速连点时会和真正的结果叠在一起，看起来像"所有人都被打死了"）。
- **演出期间点不动**：牌桌正在演（刀光、飘血、揭晓、播报）的时候，
  出拳和行动按钮会**变灰、点下去不算数**，等这一轮演完自动恢复 ——
  这是为了防止"画面还没演完就又把下一步点出去了"。
  房间里那几个按钮（开始 / 离开 / 邀请 / 加人机）不受影响，随时能按。
- **地图和头像会跟着屏幕放大**：竖屏手机上地图尽量吃满宽度，头像和它的点击热区
  在 360px 宽的小屏上也有 60px 以上（手指点得到）。

## 一点玩法心得（不是规则）

- 猜拳是纯运气，但**赢的时机**决定了这局好不好打：先手买刀买马，比先去砍人划算。
- 有马的人**在同一座城里**最危险（3 点血 + 踹出城），站在野外相对安全，但野外也会被人用刀砍。
- 多人获胜时，**排序权在你手上**：把自己排前面，可以先把对手打残，让他这回合没法反击。
- 硬拖到 10 秒不出拳并不是什么好策略 —— 系统会替你随机出。

## 规则的第二事实来源

这份 README 是给玩家看的版本，界面上的「游戏规则」页是它的界面版。
**真正说了算的是代码**，规则改动请以这两处为准：

- `js/engine/rules.js` —— 「有哪些操作可以选」的唯一实现（界面按钮、服务器校验、AI 决策都用它）
- `js/engine/engine.js` —— 状态机本体（回合流程、伤害、胜负）

改规则时这三处要一起改：README、界面上的规则页、`js/engine/**`。
