# 💥 大炮轰小鬼 / Cannon Goblin

一个不对称对抗的网页棋盘游戏，两人对战。零依赖、零构建。

> 本游戏是 **frp-game 平台**上的三个游戏之一，账号、好友、房间都由平台提供。
> 从平台首页进入本游戏，或者直接访问 `/games/cannon-goblin/`。
>
> 原独立站点仍在线（https://produce123.github.io/Cannon-Goblin/），但那份代码是
> "没有服务器"时代的版本；本目录是**平台版**，联机方式完全不同。

## 玩法

棋盘上一方是**大炮**（💣，数量少），另一方是**小鬼**（👻，数量多）。

| | 怎么走 | 怎么赢 |
|---|---|---|
| 💣 大炮方（**先手**） | 走一格；或者**隔着恰好一个空格吃掉一个小鬼** | 把小鬼吃到**数量不多于自己** |
| 👻 小鬼方 | 只能走一格 | 让**所有大炮一步都走不了** |

关键就是那"恰好一个空格"：大炮不能吃贴着自己的小鬼，也不能隔两个吃。
所以小鬼贴上来是安全的，但也因此永远吃不到大炮 —— 小鬼要靠**站位**一点点把大炮堵死。

三种预设地图：**经典对战**（6×6，2 炮 18 鬼）、**广阔天地**（8×8）、**狭路相逢**。

## 三种玩法

- **本地对局** —— 两个人同一台电脑轮流走。
- **人机对局** —— 三档难度：简单（看 1 步）、普通（看 2 步）、困难（迭代加深，算到 1.5 秒为止）。
  可以选自己执哪一方。困难档思考时会短暂占住界面约 1.5 秒，属正常。
- **在线对局** —— 建房拿到 6 位房间号，或者输入朋友的房间号加入；
  还能一键把在线好友请进来。房主在准备界面选**自己执哪一方**和**用哪张地图**，
  也可以进地图编辑器自己摆一个局面。
  一个人也能开局：房主按一下「＋ 添加人机」就多一个**人机座位**（单字名字、灰色虚线圈头像，
  和真人一样出现在成员列表里、一样能对它扔鸡蛋/送鲜花）。真人来了会先顶掉最后加的那个人机，
  所以人机永远不会挡着朋友进来。
- **头像互动** —— 点别人的头像可以扔鸡蛋 🥚 或送鲜花 🌸（不限次数），
  两边都能看到抛物线特效和音效。
- **看得清每一步** —— 服务端一次推来的多步会**逐个演完**（约半秒一步，不跳过、不能快进），
  走子是滑动、吃子会叠一层碎掉的残影 + 一声闷响。
  **点下去本机不预演**：画面上"我这一手"由服务器回放的那一步演出来（宁可等一下，
  也不让画面和真实局面打架）；**演出期间棋盘会变灰、点不动**，演完自己松开 ——
  免得"一边看动画一边接着操作"。棋盘底栏和首页各有一对「音效 / 特效」开关。

## 目录

```
index.html      全部界面（切屏靠 .screen.is-active，不用路由）
css/style.css   全部样式
js/engine/      规则引擎（同时被服务器 import —— 服务端权威裁决）
js/ai/          人机 AI
js/view.js      界面唯一允许读的视图层
js/bridge.js    把引擎挂回 window，供经典脚本使用
js/ui/          界面控制 / 在线对局 / 音效
tests/          node:test 用例 + AI 自我对弈压测
```

## 开发者怎么验证

```bash
node tools/check-game.mjs cannon-goblin            # 骨架 + 零 DOM + 服务端契约 + 跑用例
node tools/check-game.mjs cannon-goblin --browser  # 再加真浏览器（含界面体检）
node games/cannon-goblin/tests/sim.mjs 4 normal    # AI 自我对弈压测（慢）
```

**改代码之前先读本目录的 `AGENTS.md`**（这个游戏自己的坑）
和仓库根目录的 `docs/GAME-SPEC.md`（所有游戏共同的规矩）。

## 版本史

原本是个纯静态站点，联机靠公共 MQTT broker + WebRTC 打洞（因为玩家没有服务器）。
现在跑在自己的服务器上，规则由服务器裁决，那约 145 KB 的"没有服务器"代码已经整段删除。
详见 `AGENTS.md` 的"已删掉的东西"。
